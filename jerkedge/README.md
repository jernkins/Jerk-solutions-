# JerkEdge

**Your world. Your edge.**

JerkEdge is a mobile-friendly, browser-inspired start page built with plain HTML, CSS, and JavaScript.

## Features
- Responsive dark-purple interface
- Search the web or enter a website address
- Quick links to YouTube, Google, GitHub, ChatGPT, Instagram, and X
- No build tools or dependencies required

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
The workflow in `.github/workflows/jerkedge-pages.yml` publishes the contents of this folder when changes are pushed to `main`. In your repository, open **Settings → Pages** and ensure the publishing source is **GitHub Actions**.

Note: JerkEdge is currently a browser-style website/start page, not a standalone web browser engine.
