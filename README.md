# Jerk Solutions — Starter Website

**Slogan:** Innovate. Build. Empower.  
**Tagline:** Technology beyond limits.

## Publish with GitHub Pages
1. Open repository Settings → Pages.
2. Choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`, then Save.
4. Wait for GitHub Pages to publish. The URL will appear on that page; it may resemble `https://jernkins.github.io/Jerk-solutions-/`.
5. Test the website on your phone.

## Before launch
- Add a dedicated business email to the Contact section.
- Check name, handle, domain and trademark availability.
- Keep roadmap items labelled as planned until they work.
- GitHub Pages hosts static websites; it does not provide a secure backend/database by itself.
